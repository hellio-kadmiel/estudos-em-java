# Estudos de Java

Repositório com exercícios e projetos de Java, organizado por tema.

## 📁 Pastas e Conteúdos

### Fundamentos
- **Primeiros_codigos** - Primeiros códigos e testes de Java.
- **Curso_programacao** - Anotações e exercícios do curso de Java.
- **Atividade_Apostila** - Exercícios baseados em apostila de Java.

### Estruturas de Dados
- **Vetores** - Exercícios com vetores (arrays unidimensionais).
- **Exercicios_Vetores** - Exercícios adicionais utilizando vetores.
- **desafio_vetores** - Exercícios/desafios específicos de vetores.
- **Matrix** - Exercícios com matrizes (arrays multidimensionais).
- **Listas** - Exercícios com listas e coleções.
- **Exercicio_Listas** - Exercícios práticos de listas.

- **Composicoes** - Exercícios de composição de classes.
- **Composicoes_02** - Segunda série de exercícios de composição de classes.
- **Heranca** - Exercícios sobre herança e polimorfismo.
- **HerancaMultipla** - Estudos sobre herança múltipla e interfaces.
- **Polimorfismo/src** - Exemplos de polimorfismo.
- **PolimorfismoExercicio/src** - Exercícios/desafios específicos de polimorfismo e sistema de cadastro de produtos e imposto.
- **Enum** - Exercícios com enumerações.
- **Interfaces** - Estudos sobre implementação de interfaces.
- **ExercicioInterfaces** - Exercícios práticos de interfaces.

### Generics
